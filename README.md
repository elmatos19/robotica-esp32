# robotica-esp32

Projetos de robótica e eletrónica com ESP32, Arduino e sistemas embarcados, desde os primeiros circuitos até à construção de um robô autónomo.

O objetivo é começar pelos fundamentos, utilizando um ESP32, e evoluir progressivamente para projetos mais complexos, incluindo sensores, motores, comunicação WI-FI e, futuramente, um robô autónomo.

Objetivos:

- Aprender eletrónica na prática;
- Aprender a programar microcontroladores;
- Desenvolver projetos com ESP32;
- Trabalhar com sensores e atuadores;
- Controlar motores;
- Compreender comunicação e sistemas embarcados;
- Construir progressivamente um robô autónomo;

Projetos:

Projeto 01- LED com ESP32

Conceitos aprendidos:

-  GPIO;
- 'pinMode()';
- 'digitalWrite()';
- 'delay()';
- 3.3V e GND;
- Breadboard;
- Resistência e polaridade de LED;

Próximos projetos:

- Botão + LED;
- Semáforo;
- Sensores;
- Sensor de distância;
- Servo motor;
- Controlo de motores DC;
- Carro robotizado;
- Comunicação WI-FI;
- Robô autónomo;

Hardware:

- ESP32;
- Breadboard;
- LEDs;
- Resistências;
- Jumpers;
- Sensores;
- Motores DC;
- Driver de motores TB6612FNG;
- Chassis 2WD;

Objetivo Final:

Construir um robô autónomo baseado em ESP32, aplicando progressivamente os conhecimentos adquiridos ao longo dos projetos.
