Projeto 01 - Controlo de LED com ESP32

Sobre o projeto:

Este foi o meu primeiro projeto prático para este portfólio com um ESP32.
O objetivo foi aprender os conceitos básicos de eletrônica e programação de um microcontrolador, utilizando um LED externo ligado ao GPIO 23.
O LED é ligado e desligado automaticamente a cada segundo através de um programa desenvolvido no Arduino IDE.

Objetivos:

- Fazer o primeiro circuito com o ESP32;
- Aprender a utilizar uma breadboard;
- Compreender GPIOs;
- Aprender a utilizar 'pinMode()';
- Aprender a utilizar 'digitalWrite()';
- Compreender "HIGH" e "LOW";
- Utilizar uma resistência para proteger o LED;
- Compreender a importância da polaridade do LED;
- Fazer o upload de um programa para o ESP32;

Componentes:

- ESP32;
- Breadboard;
- LED;
- Resistência de 220 ohms;
- Cabos jumper;
- Cabo USB;

Ligações:

O LED foi ligado ao GPIO 23 do ESP32 através de uma resistência de 220 ohms.
